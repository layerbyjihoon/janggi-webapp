# 프로젝트 관리 TASK-04: 통합 리스크와 릴리즈 게이트

## 목적

상위 리스크를 지속 추적하고, 릴리즈 차단 조건을 QA와 함께 잠근다.

## 오너

- PM

## 선행 조건

- `TASK-03-크리티컬-패스-운영.md`

## 입력물

- QA 결함 현황
- FE/BE fixture 비교 결과
- transposition 통합 검증 결과

## 작업 내용

1. FE/BE key mismatch, 중복 노드 생성, 문서형 UX 잔재를 상위 리스크로 유지한다.
2. P1 결함, key mismatch, transposition 실패를 릴리즈 차단 조건으로 확정한다.
3. 부분 완료 항목과 우회 경로를 릴리즈 범위에서 분리한다.
4. 최종 게이트 통과 전 역할별 완료 기준 충족 여부를 점검한다.

## 산출물

- 리스크 로그
- 릴리즈 게이트 체크 기록
- 차단 항목 해제 승인 메모

## 수용 기준

- 릴리즈 차단 조건이 QA와 완전히 일치한다.
- 상위 리스크마다 조기 신호와 대응 방안이 기록돼 있다.
- Gate 통과 여부를 문서만으로 판단할 수 있다.

## 차단 시 에스컬레이션

- P1 결함이 1건이라도 열려 있으면 릴리즈 게이트를 열지 않는다.
