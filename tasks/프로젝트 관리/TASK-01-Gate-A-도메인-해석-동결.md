# 프로젝트 관리 TASK-01: Gate A 도메인 해석 동결

## 목적

`연구 문서/분기 트리` 모델을 완전히 폐기하고 `유저당 단일 Position Graph` 모델을 전체 팀 용어로 고정한다.

## 오너

- PM

## 선행 조건

- 없음

## 입력물

- `docs/세부 기획서 - 프로젝트 관리.md`
- 기존 역할별 세부 기획 문서

## 작업 내용

1. 문서형 용어와 단일 그래프 용어를 비교한 변경 로그를 작성한다.
2. `새 연구`, `최근 연구`, `문서 저장` 관련 잔존 요구를 제거 대상으로 표시한다.
3. `포진명은 현재 포지션에 귀속된다`는 원칙을 역할별 문서 공통 규칙으로 명시한다.
4. UX/UI, FE, BE, QA에 동일 용어 세트를 배포한다.

## 산출물

- 변경 로그
- 용어 동결 메모
- 문서형 잔재 제거 목록

## 수용 기준

- 모든 역할 문서가 저장 단위를 `PositionNode/Graph` 기준으로 설명한다.
- 문서형 흐름이 핵심 사용자 여정에서 제거되었다.
- QA가 이 기준만으로 요구사항 검증 케이스를 작성할 수 있다.

## 차단 시 에스컬레이션

- 문서형 요구가 2개 이상 역할 문서에 다시 등장하면 즉시 Gate A 재검토를 연다.
