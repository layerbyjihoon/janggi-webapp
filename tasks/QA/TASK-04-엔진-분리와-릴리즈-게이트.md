# QA TASK-04: 엔진 분리와 릴리즈 게이트

## 목적

엔진 실패가 formation lookup 흐름을 깨지 않는지 검증하고, 릴리즈 차단 조건 충족 여부를 최종 확인한다.

## 오너

- QA 리드

## 선행 조건

- `TASK-03-transposition과-저장-무결성-회귀.md`
- 프론트엔드 엔진 상태 분리 문서

## 입력물

- 엔진 실패 내성 요구사항
- 프로젝트 관리 릴리즈 게이트 기준

## 작업 내용

1. 엔진 초기화 실패, 분석 중지, Worker 오류 상황을 만든다.
2. 포지션 lookup과 포진명 표시가 계속 동작하는지 확인한다.
3. 엔진 오류와 포진 미등록을 사용자가 구분할 수 있는지 검증한다.
4. P1 결함, key mismatch, transposition 실패 여부를 릴리즈 기준으로 체크한다.

## 산출물

- 엔진 실패 검증 결과
- 릴리즈 게이트 점검표
- 최종 결함 분류 메모

## 수용 기준

- 엔진 실패가 formation lookup 흐름을 깨지 않는다.
- P1 결함 여부를 명확히 판정할 수 있다.
- 릴리즈 차단 조건이 프로젝트 관리 문서와 일치한다.

## 차단 시 에스컬레이션

- 엔진 오류가 미등록 포지션처럼 보이면 릴리즈 게이트를 즉시 차단한다.
