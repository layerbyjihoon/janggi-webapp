# UXUI TASK-03: 상태 명세와 transposition 표현

## 목적

등록 포지션, 미등록 포지션, lookup 대기, 오류, transposition 상태를 사용자가 혼동하지 않도록 정의한다.

## 오너

- UX/UI 리드

## 선행 조건

- `TASK-02-단일-그래프-작업-공간-와이어프레임.md`
- 백엔드와 프론트엔드의 상태 초안 수신

## 입력물

- lookup 응답 예제
- transposition 시나리오

## 작업 내용

1. 등록, 미등록, 로딩, 오류 상태의 라벨과 보조 문구를 정의한다.
2. transposition으로 같은 포지션이 재사용된다는 점을 설명하거나 암시하는 UI 표현을 정한다.
3. 별칭 노출과 설명 필드 노출의 우선순위를 정한다.
4. 엔진 오류와 포진 미등록이 시각적으로 겹치지 않게 규칙을 만든다.

## 산출물

- 상태 명세서
- transposition 표현 가이드
- 패널 문구 표

## 수용 기준

- QA가 상태별 기대 결과를 문서만 보고 판별할 수 있다.
- FE가 상태 머신에 필요한 라벨과 우선순위를 그대로 구현할 수 있다.
- 미등록 상태가 오류처럼 보이지 않는다.

## 차단 시 에스컬레이션

- transposition 표현이 중복 노드처럼 오해될 가능성이 크면 가이드를 단순화한다.
