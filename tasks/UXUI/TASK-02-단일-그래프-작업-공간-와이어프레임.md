# UXUI TASK-02: 단일 그래프 작업 공간 와이어프레임

## 목적

보드, 포진명, 이웃 탐색, 엔진 패널을 한 화면에서 이해할 수 있는 작업 공간 구조를 정의한다.

## 오너

- UX/UI 리드

## 선행 조건

- `TASK-01-정보구조와-용어-정리.md`

## 입력물

- 역할별 우선순위 요구사항
- 레퍼런스 지침

## 작업 내용

1. 장기판 중심 레이아웃과 사이드 패널 영역을 나눈다.
2. 현재 포진명 영역을 첫 시선 안에 들어오도록 배치한다.
3. 인접 포지션 탐색 영역과 엔진 패널의 시각적 분리를 정리한다.
4. 전체 그래프 강제 시각화 대신 현재 포지션 중심 탐색 구조를 설계한다.

## 산출물

- 작업 공간 와이어프레임
- 영역별 우선순위 메모
- 모바일/데스크톱 레이아웃 노트

## 수용 기준

- 사용자가 진입 즉시 현재 포지션과 포진명 유무를 이해할 수 있다.
- FE가 레이아웃 질문 없이 주요 패널 구조를 구현할 수 있다.
- 엔진 패널이 포진명 정보와 시각적으로 분리된다.

## 차단 시 에스컬레이션

- 포진명 영역이 보드 주변의 보조 정보처럼 밀리면 레이아웃을 재조정한다.
