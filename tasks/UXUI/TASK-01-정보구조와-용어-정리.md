# UXUI TASK-01: 정보구조와 용어 정리

## 목적

단일 Position Graph 작업 공간에 맞는 정보 구조와 라벨 체계를 정의하고, 문서형 UX 잔재를 제거한다.

## 오너

- UX/UI 리드

## 선행 조건

- 프로젝트 관리 Gate A 완료

## 입력물

- `docs/세부 기획서 - UXUI.md`
- 프로젝트 관리 용어 동결 메모

## 작업 내용

1. `새 연구`, `최근 연구`, `문서 저장` 계열 용어를 제거한다.
2. 현재 포지션, 포진명, 인접 포지션, 엔진 패널 중심의 정보 구조를 정리한다.
3. `현재 포진명`과 `수순명`이 혼동되지 않도록 라벨 규칙을 만든다.
4. 미등록 포지션 상태 문구의 톤과 길이를 정의한다.

## 산출물

- 용어 사전
- 정보 구조 초안
- 제거 대상 UX 목록

## 수용 기준

- FE가 문서형 화면 없이도 레이아웃 우선순위를 이해할 수 있다.
- QA가 문서형 잔재 여부를 문구 수준에서 검증할 수 있다.
- 포진명이 현재 포지션 귀속 정보라는 점이 명확하다.

## 차단 시 에스컬레이션

- 문서형 용어가 핵심 화면 정의에 남아 있으면 Gate A 재검토를 요청한다.
