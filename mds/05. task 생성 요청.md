## 요구사항
각 지시사항을 별개의 task-distributor 로 실행

## 지시사항
1. [QA 세부기획서](<../docs/세부 기획서 - QA.md>) 를 읽고 `tasks/QA` 폴더에 task 파일들 작성해줘. task들을 관리하기 위한 체크리스트도 만들어줘
2. [UXUI 세부기획서](<../docs/세부 기획서 - UXUI.md>) 를 읽고 `tasks/UXUI` 폴더에 task 파일들 작성해줘. task들을 관리하기 위한 체크리스트도 만들어줘.
3. [백엔드 세부기획서](<../docs/세부 기획서 - 백엔드.md>) `tasks/백엔드` 폴더에 task 파일들 작성해줘. task들을 관리하기 위한 체크리스트도 만들어줘.
4. [프로젝트 관리 세부기획서](<../docs/세부 기획서 - 프로젝트 관리.md>) `tasks/프로젝트 관리` 폴더에 task 파일들 작성해줘. task들을 관리하기 위한 체크리스트도 만들어줘.
5. [프론트엔드 세부기획서](<../docs/세부 기획서 - 프론트엔드.md>) `tasks/프론트엔드` 폴더에 task 파일들 작성해줘. task들을 관리하기 위한 체크리스트도 만들어줘.
